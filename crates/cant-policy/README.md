# cant-policy

Capability model: access rights, powerbox argument grants, protected paths and attenuation (`intersect`) for [Cantainer](https://github.com/cantainer/cantainer), which runs every executable as a least-privilege capsule.

This is an internal crate of the `cant` tool (crate `cantainer`). Its API is not stable.
