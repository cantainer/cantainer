# cant-launch

Sandbox setup and exec: ELF library resolution, Landlock rules, seccomp filters. Linux only; other systems get stub errors for [Cantainer](https://github.com/cantainer/cantainer), which runs every executable as a least-privilege capsule.

This is an internal crate of the `cant` tool (crate `cantainer`). Its API is not stable.
